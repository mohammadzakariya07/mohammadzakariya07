## About Me

I’m an Embedded Systems Engineer focused on **firmware development, hardware interfacing, PCB design, prototyping, and product development**. I work with microcontrollers and electronics to develop, integrate, test, and debug practical embedded solutions.

- **Firmware:** Embedded C/C++, peripheral interfacing, debugging, state machines, and non-volatile data storage
- **Microcontrollers:** PIC, STM32, AVR, Arduino, and ESP32
- **Communication:** UART, I²C, and SPI
- **Peripherals:** GPIO, timers, interrupts, PWM, ADC, EEPROM, sensors, displays, and relay modules
- **Hardware & PCB:** Circuit design, schematic capture, PCB design, simulation, and prototype testing
- **Development tools:** MPLAB X IDE, STM32CubeIDE, Arduino IDE, KiCad, EasyEDA, and Proteus

## Featured Projects

> Add each project's repository URL to its title once that repository is published. Keep the README, wiring/pin mapping, hardware photos, and test results together in each project repository.

### 1. Smart Temperature Relay Controller
Temperature-based multi-stage relay control using a K-type thermocouple interface, Arduino, EEPROM, and an OLED display. Implements threshold-based switching and persistent configuration/state handling.

**Technologies:** Embedded C/C++, Arduino, MAX6675, EEPROM, OLED, relays

### 2. Multi-Door Interlock System
Coordinated door-locking logic using PIC microcontrollers and UART communication, designed to prevent other doors from unlocking while one door remains open.

**Technologies:** Embedded C, PIC16F887, UART, GPIO, timers, interlock logic

### 3. STM32 DC Power Monitoring System
Monitors voltage and current with an INA219, tracks date and time using a DS1307 RTC, and transmits readings to a mobile device over Bluetooth.

**Technologies:** STM32, Embedded C, INA219, DS1307, HC-06, I²C, UART

### 4. Smart Delay Relay Control with EEPROM
Stores relay state in EEPROM and restores the intended state after power-up, with controlled sequential activation and switch debounce handling.

**Technologies:** Arduino, Embedded C/C++, EEPROM, relay modules, debounce logic

### 5. ESP32 Attendance System
Keypad-based attendance workflow with LCD feedback, EEPROM storage, and Google Sheets integration.

**Technologies:** ESP32, C/C++, keypad, I²C LCD, EEPROM, Google Apps Script

### 6. Six-Seater Electric Vehicle
Team project involving integration and prototyping of a 48 V electric vehicle with infotainment display, Bluetooth, and ultrasonic parking assistance.

**Technologies:** EV systems, embedded integration, sensors, prototyping

### 7. IoT Home Automation
Sensor-assisted home automation using ESP32, relay outputs, and ultrasonic sensing.

**Technologies:** ESP32, IoT, relays, ultrasonic sensors
